# Example pack: Suwa

The standards pack from [Suwa](https://github.com/thusalapi/Suwa), a self-hosted clinic and lab management system for small medical centres in Sri Lanka. In the real repo these files sit at the repo root under `.claude/`.

| File | Covers |
| --- | --- |
| [`suwa-build`](.claude/skills/suwa-build/SKILL.md) | Locked decisions, target layout, session routine with `PROGRESS.md` |
| [`suwa-frontend`](.claude/skills/suwa-frontend/SKILL.md) | Next.js App Router, hand-built Tailwind, atomic design, design tokens, forms, i18n, accessibility |
| [`suwa-backend`](.claude/skills/suwa-backend/SKILL.md) | Server actions, Drizzle with Liquibase, tenant isolation, audit in the same transaction, gap-free numbering, backups |
| [`standards-rules.json`](.claude/standards-rules.json) | Six machine-checkable rules |

The live progress log is [`PROGRESS.md`](https://github.com/thusalapi/Suwa/blob/main/PROGRESS.md) in the Suwa repo.
