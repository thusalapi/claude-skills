# Explainer Reel

A Claude skill and Python toolkit that turns a short JSON script into a finished 9:16 education video for Reels, Shorts or TikTok. It handles the voice, captions, motion graphics, sound mix and a cover that survives platform crops.

## Why I built it

I made this to run a weekly education series for a family furniture business. Small businesses have good footage of their work but no time for editing. With this skill, Claude writes the script from the business's confirmed facts, picks clips, builds the spec, checks a contact sheet, renders the video and prepares the cover. The owner only reviews and approves.

## What it does

- **Offline AI voice** with [Kokoro](https://github.com/thewh1teagle/kokoro-onnx). No API key, no per-minute cost. Lines are cached, so editing one line only re-voices that line.
- **Animated captions** that brighten word by word, timed from the voice length.
- **Motion graphics** drawn frame by frame with Pillow and NumPy: masked headline reveals, counters, dimension lines, bullet cards, an isometric layer diagram and an end card with a call to action.
- **Real footage handling**: feathered band, warm colour grade, slow push-in, film grain, still photos with a blurred fill.
- **Sound mix**: voice on top, music ducked under the voice, footage ambience, cue-timed effects, mastered to -14 LUFS and -1.5 dBTP with FFmpeg `loudnorm`.
- **Licence-free effects**: `make_sfx.py` synthesises the whole effect kit from noise and sine waves.
- **Crop-safe covers** with a preview of the 4:5 feed and 1:1 grid crops.
- **Fast iteration**: `--stills` renders a contact sheet in seconds, `--only` re-renders single scenes.

## How the skill works

`SKILL.md` gives Claude a production process, not just a script runner:

1. Read the brand profile (`references/brand-profile-template.md`), the only allowed source of facts.
2. Write a 6 to 8 scene script with a hook, an open loop, numbered points, proof and one call to action.
3. Apply truth rules: real footage for real work, sourced claims only, nothing posted without approval.
4. Check a contact sheet and the cover crops before spending minutes on a full render.
5. Run a quality checklist (safe margins, no duplicated text, loudness, file size).

## Use it

**In Claude Code:**

```
/plugin marketplace add thusalapi/claude-skills
/plugin install explainer-reel@thusala-skills
```

Then ask: *"Make an explainer reel about how our tables are finished, using the clips in ./footage."*

**In the Claude app:** download this folder as a zip and upload it under Settings > Capabilities > Skills.

**Without Claude:**

```bash
bash scripts/setup_assets.sh          # once: packages, voice model, fonts, effects
cd examples/demo
python3 ../../scripts/reel.py demo.json --stills check.jpg   # quick look
python3 ../../scripts/reel.py demo.json --cover cover.jpg    # cover + crops
python3 ../../scripts/reel.py demo.json                      # full render
```

Requires Python 3.10+ and FFmpeg. A 30-second render takes about 5 minutes on a laptop CPU.
